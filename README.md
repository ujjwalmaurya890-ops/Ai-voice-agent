# 🎙️ CampusVoice AI

An AI-powered Windows desktop assistant built with **Google Gemini Live API** to support college study, voice conversations, and everyday productivity.

## ✨ Features
- 🎤 Real-time voice interaction
- 📚 College study and question assistance
- ✅ Task and deadline management
- 📝 Notes and productivity tools
- 🔐 Secure API key handling
- 🖥️ Windows desktop interface

## 🛠️ Tech Stack
- Python
- Google GenAI SDK
- Gemini Live API
- Windows desktop tools

## 🚀 Getting Started

1. Download or clone this repository.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Configure your Gemini API key using the provided `.env.example` instructions.
4. Run the application using the startup instructions in the project README.

## 🔒 Security
Never commit API keys, `.env` files, or other sensitive credentials to GitHub.
